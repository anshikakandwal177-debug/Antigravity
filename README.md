## 🎨 Key Features

1. **Modern Data-Themed UI:**
   - Dark theme default with a sleek glowing aesthetic, plus an instant ☀️ / 🌙 light mode switch.
   - Interactive SQL terminal widget right in the hero section.
2. **Interactive SQL Lab Showcase:**
   - Tabbed queries showcasing **Window Functions (RFM)**, **Recursive CTEs**, **3NF DDL Relational Schemas**, and **LAG/LEAD Churn Analytics**.
   - Built-in one-click "Copy SQL" button with visual feedback.
3. **Project Filtering & Detail Modals:**
   - Filter projects by *All*, *SQL & Schemas*, *Python & EDA*, or *BI & Analytics*.
   - Click "View Query & Architecture" to open deep-dive modals explaining the business problem, schema normalization, and results.
4. **Recruiter-Friendly Contact Section:**
   - "Copy Email" one-click action with toast notification.
   - Quick links for LinkedIn and GitHub.

## 🌐 Free 1-Minute Deployment Options

### Option 1: GitHub Pages (Recommended)
1. Create a GitHub account at [github.com](https://github.com).
2. Create a new repository named `portfolio` (or `<your-username>.github.io`).
3. Upload `index.html`, `styles.css`, and `script.js`.
4. Go to **Settings** $\to$ **Pages** $\to$ select `main` branch $\to$ click **Save**.
5. Your live link will be: `https://<your-username>.github.io/portfolio`.

### Option 2: Netlify (Drag & Drop)
1. Go to [netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `antigravity` folder.
3. Your portfolio goes live instantly with an SSL-secured URL you can add to your resume!
